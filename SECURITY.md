# Security Policy

## Supported versions

Only the latest 0.x release of Flarelet receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Private vulnerability reporting**:

1. Open the [Security tab](https://github.com/youyo/flarelet/security) of the repository.
2. Click **Report a vulnerability** and describe the issue, the affected version, and how to reproduce it.

Do **not** open a public issue, pull request or discussion for a security problem, and do not include real credentials or AWS account details in a report.

You will get an acknowledgement as soon as the maintainer can respond. Once a fix is released, the advisory is published with credit to the reporter (if you want it).
