# Flarelet v0 Design Bundle

This bundle contains the current Flarelet v0 architecture and product design agreed during brainstorming.

- `FLARELET_V0_DESIGN.md` — canonical design specification

Core direction:

- TypeScript
- AWS CDK + CloudFormation
- serverless-first
- YAML + CLI user experience
- authentication by default
- App → Stage → Version deployment model
- Git branch mapping and ephemeral PR previews
- stage-scoped stateful resources / version-scoped compute
